    REA Forensic Architecture Teardown — mydigitalclinic.net (PULSE PMS) Evidence ID: ev_97304797f878... & ev_bfd85608eb70...

    1. Rendering Setup & Frontend Stack

    • Server Engine: ASP.NET MVC 5 on IIS (x-aspnet-version, x-aspnetmvc-version, Razor view path ../Controller/Account/Login.cshtml, CSRF protection via __RequestVerificationToken).
    • Design System: Bootstrap 4 + Bootstrap Material Design (bootstrap-material-design.css / .js + material.js + ripples.min.js) bootstrapped via $.material.init().
    • Canvas & Rich Widgets: jquery.easy-pie-chart.js renders 2D HTML5 <canvas> circular KPI gauges; wysihtml5-0.3.0.js provides rich-text clinical note editing; DataTables (dt-bootstrap4) drives tabular registers.

    2. Animation Drivers & Scroll Motion

    • Skeleton Shimmer Driver: @keyframes placeHolderShimmer translates a 3-stop linear gradient (#eee → #e9e9e9 → #eee) from -468px to +468px over 1.25s linear infinite on .animated-background.
    • 3-Dot Box-Shadow Wave Loader: @keyframes load7 animates .loadingImage and its :before/:after pseudo-elements with staggered -0.32s and -0.16s delays.
    • Multi-Region Pinned Scroll Architecture: Fixed 70px topbar (.navbar-fixed-top), fixed 58px collapsible sidebar (.main-sidebar), pinned patient header (.PatientDetailtitlerow at top:70px), horizontal 7-day flex scroller (.DayScrollItem at 14.28% width), and horizontal Masonry pill scroller (.MasonaryTopbar .nav with hidden scrollbars).

    3. Post-Processing & Textures

    • Full-Bleed Fixed Background Texture: /Content/images/background.png (1,019,183 bytes) is pinned via a dual body + body::after fixed compositor layer (z-index: -1; background-size: cover).
    • CSS Filter Post-Processing: The colour Pulse-logo.png (77,852 bytes) is converted to a crisp monochrome white mark over the linear-gradient(160deg, #512da8, #5dbdb9) card using filter: brightness(0) invert(1).

    4. Pages, Backend Data & API Flows

    • Auth & Onboarding: Form POST to /account/login + synchronous AJAX GET /Account/VerifyUserName?userName=... inside the 3-step RhinoSlider registration wizard (step1_validation → step2_validation → step3_validation).
    • PWA Service Worker: /serviceWorker.js implements v1.0::CacheFirstSafe (network-first for text/html, cache-first for versioned ?v= assets, dynamic SVG generator for offline images).
    • Clinical AJAX Modules: .sidebar-list-item-AjaxLoad dynamically swaps patient sub-views (Odontogram #desktopDentalChart, Case Timeline .timeline, Billing #billingList, Wallet .walletCard, and Bulk SMS #bulkSMSIcon).
